📓 Thought Journal

A minimalist, full-stack web application built with Java and Spring Boot for clean, aesthetic micro-journaling.

🛠️ Tech Stack & Features
Backend: Java 17, Spring Boot 3.2.5, Spring Data JPA
Frontend: HTML5, CSS3, JavaScript
Database: H2 Database (In-Memory)
Features: Minimalist UI, mood color tagging, robust data persistence

🚀 Getting Started

1. Clone & Navigate


git clone https://github.com
cd Thought-Journal


2. Run Application

./mvnw spring-boot:run


3. Access App
Web UI: [http://localhost:8080](http://localhost:8080)
H2 Console: [http://localhost:8080/h2-console](http://localhost:8080/h2-console) (JDBC URL: `jdbc:h2:mem:testdb`)
